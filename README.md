> StorySpark is an AI-powered story and poem generator that helps users create new and exciting content based on their input. With just a few prompts, users can generate entire stories or poems, making it a great tool for writers, students, and anyone looking for inspiration.

## ✨ Features

- Generate stories based on user prompts
- Generate poems based on user prompts
- Customizable tone and style

## 🛠 Tech Stack

- Frontend: Pure HTML / CSS / JavaScript
- Backend: Vercel Serverless Functions (Node.js)
- AI: Groq API (Llama 3.3 70B)
- Groq AI API via Vercel serverless function + Web Speech API for voice input
- Dark theme with glassmorphism UI
- Fully responsive (mobile + desktop)
